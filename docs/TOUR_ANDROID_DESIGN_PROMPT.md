## 要做什么

为手机导览应用「Ari Travel」的 Android 版出一组效果图。

它已经有一个在用的网页版，App 会把网页版原样装进去，再加四个网页做不到的功能。**这次要设计的是这四个功能的界面，以及贯穿其中的 agent 形象。agent 不止一个形象，是一组可以换的导览员。** 已有的界面不用重新设计，但新东西和它们放在一起，要看不出是两个人做的。

如果这个项目里已经有「AriTour」原型和它的 Classical 设计系统，直接沿用。下面的视觉规格与那一套相同，是给没有原型时对照用的。

## 产品与使用场景

Ari Travel 是景区和博物馆的现场导览。游客到了景区打开它，看到一张导游地图，选一条参观路线；走进某个景点的「热区」，它就推送这一处的讲解；讲解下面可以向 AI 导览助手提问。

**它是多景区的，设计不要为哪一处量身定制。** 现在上线的是长春的伪满皇宫博物院，接下来至少会加北京的北海公园、香山公园、颐和园。组件里不能有只属于某个景区的图案、配色或文案；景区名、地点名、评级都是填进去的内容。

这几处差别很大，同一套设计都要装得下：

- 伪满皇宫是紧凑的院落，热区一个挨一个，走几十米就到下一处，不少内容在室内。
- 北海、颐和园、香山是大园子和山，两处热区之间可能要走十几分钟，中间很长一段时间 agent 无事可做。
- 资料齐全的程度不一样：有的地点没有照片，有的景区还没有路线和建议停留时间。
- 地点名有短有长：「团城」「九龙壁」只有两三个字，「东北沦陷史陈列馆」「兰徽幻影——溥仪“御纹章”文物展」很长，有的还带引号。

设计时请一直想着这个人：在室外边走边看，常常只有一只手空着，阳光直射屏幕，手机多半揣在兜里，或者拿在手上却没在看。所以四个新功能是同一个方向：不用盯着屏幕也能用。到了地方它自己开口，想问什么张嘴就问。

1. **语音问答**：景点介绍下面的提问，除了打字还可以按住说话，回答可以朗读。
2. **悬浮窗**：App 退到后台之后，屏幕上留一个 agent 的头像，浮在别的应用上面，随时可以打字或说话提问。
3. **后台到站提醒**：App 不在前台时照样定位，走进热区就弹出提示，agent 同时用语音和文字提醒。
4. **语音唤醒**：对着手机说唤醒词，agent 就开始听。

## 视觉语言（沿用，不要另起一套）

气质是旧书页与铜版地图：暖灰的纸色底、近黑的字、一种古铜金作强调色；细线、小圆角、几乎没有填充色块；西文用衬线体。克制。没有渐变、毛玻璃、彩色插画和表情符号。

**颜色**

| 用途 | 值 |
|---|---|
| 页面底 / 次级面 | `#f3f2f2` / `#eae9e9` |
| 文字 | `#201f1d` |
| 分隔线 | `rgba(32,31,29,0.16)` |
| 强调色（古铜金） | `#b68235` |
| 强调色的深浅 | 深 `#7d5411`（文字、选中态的实底）、更深 `#5a3b0a`、中 `#e1ad66`、浅 `#ffe3bf` 与 `#fff3e4` |
| 中性灰阶 | `#f8f4f4` `#eae7e7` `#d7d3d3` `#bab6b6` `#9b9797` `#7d7979` `#605d5d` `#444141` `#2d2b2b` |
| 淡金底纹 | `rgba(182,130,53,0.07)`，用在引用块和 AI 回答的底 |

**字体**

- 西文标题 Cormorant Garamond（600，大标题用 400），西文正文 Lora，数字用等宽数字。
- **中文用系统默认黑体**（Noto Sans SC 或 MiSans 这一类）。不要用中文衬线体，App 里没有带。
- 字号：正文 15 / 行高 1.55；介绍正文 14.5 / 1.75，两端对齐；抽屉大标题 32；卡片标题 26；顶栏标题 22；小标题 20。
- 小眉题（kicker）：10.5，全大写，字距 0.14em，深金色。

**形状**

- 圆角很小：按钮、输入框、卡片 4px；横幅 7px；底部抽屉的顶角 18px；路线 chip 是全圆角胶囊。
- 按钮是描边的，不是实底：主按钮金色描边、深金色字；次按钮灰色细描边。最小高度 44px。全站唯一的实底是选中的路线 chip（深金底、浅色字）。
- 标签：11px，3px 圆角，金色描边（如「S 级」）或浅灰底。
- 照片：6px 浅色边框外加 1px 细线，轻微泛黄、去一点饱和，像旧照片。
- 引用块与 AI 回答：左侧 2px 金色竖线，淡金底纹。
- 阴影只给浮起来的东西（横幅、抽屉）：`0 12px 32px rgba(45,43,43,0.22)`。
- 图标：1.6px 线性图标，圆头圆角（Lucide 那一类），不用实心图标。

**导游地图**，从上到下：

- 顶栏：左侧返回；中间标题「伪满皇宫」，下面一行小眉题「导游地图 · MANCHUKUO PALACE」；右侧铃铛，带未读数角标。

**介绍抽屉**：从底部滑上来，占大半屏。照片；小眉题「路线第 1 / 8 处 · 伪满皇宫」；大标题；一条分隔线；一行标签（「S 级」「建议停留约 30 分钟」「本路线第 1 站」）；馆方官网的介绍正文；「介绍出处：伪满皇宫博物院官网 · 常设展览」；然后是「游客互动」；最后是「前往下一处」和上一处 / 下一处两个按钮。

**游客互动**（介绍抽屉里的一块，语音要加在这里）：

## 要设计的内容

如果一次做不完，按这个顺序：一、三、四、五（agent 与后台这条线），然后二、六、七。

### 一、agent 的形象

这是最需要你发挥的一件。agent 是悬浮窗里常驻的那个头像，也是到站和唤醒时「开口说话的那个人」。

**它不止一个形象，是一组导览员，游客可以换。** 先做两位，以后还会加：

- **阿瑞**：名字来自产品名 Ari。
- **小爱**：名字取自爱新觉罗。伪满皇宫，以及北京的北海、颐和园，旧日的主人都姓爱新觉罗。

两位的性别、年龄、装束都不预设，请你提方案。只有一条限制：朗读用的声音目前只有一个女声，两位共用，形象不要和这个声音打架。

因为以后要能一直加人，请先定一套**共用的骨架**，再往里放人：

- **同一个构图**。56dp 的圆形头像，同样的描边和投影。在任何背景上都要看得清：它浮在别的应用上面，底下可能是白的、黑的，也可能是一张花哨的照片。
- **同一套状态**。四种：待命、在听、在想、在说，在 56dp 下一眼分得清，而且不只靠颜色区分。另有两种附加状态：有未读的到站消息（角标）；不可用（没网，或麦克风被别的应用占着），整体灰掉。状态怎么表现与是谁无关，换一位导览员，游客不用重新学。
- **同一套动效**。每个状态给一张静帧，再用一两句话说明动起来是什么样。动效要轻，它会长时间挂在屏幕上，不能烦人。
- 气泡、对话面板、通知的样式都不随人变。换人只换头像、名字和自称。

请给**两到三种明显不同的画风**供挑选。每种画风下把阿瑞和小爱都画出来，要看得出他们是一家的，又分得清谁是谁。你最推荐的那种画风，两位各画全六种状态；其余画风每位只画「待命」和「在说」。

分寸上有几条：

- 他们是导览员。不是机器人，不是客服，不是吉祥物。气质要和上面的视觉语言是一家。
- 他们跟着游客走，不属于哪一处景区。不要画成真实的历史人物，也不要借用某一处景区的建筑、服饰或徽记。
- 同一位导览员要在各种场合开口：在皇家园林里陪人散步，在抗战史和细菌战罪证的陈列前也要说「已到达」。所以要两头都站得住：不卖萌，不轻佻，也不板着脸。小爱如果取清代宫廷的元素，点到为止。
- 避开：蓝紫渐变、星光或火花这类通用的「AI」符号、3D 卡通、表情符号。

下面各节的示例帧一律用阿瑞。另外请把「头像加气泡」「对话面板展开」这两帧换成小爱各出一张，用来确认换人之后界面不用跟着改。

### 二、介绍页里的语音问答

在「游客互动」那一块上加语音，其余不动。

- 输入行多一个麦克风入口。切到语音之后，输入行变成一个整行的大按钮「按住说话」，旁边可以切回键盘。
- 按住期间出现录音浮层：实时显示已经识别出的文字（边说边出字），有音量波形，提示「松手发送，上移取消」。手指上移到取消区，提示变成「松手取消」。
- 松手之后，识别出的文字作为「我的提问」进入列表，回答的位置显示「思考中…」。回答到了自动朗读。
- 每条回答有一个朗读按钮，三种状态：未播、载入中、播放中（播放中再点就是停止）。
- 两种异常：没听清（「没有听清，请再说一次」）；达到上限（「你在 24 小时内已提问 20 条，达到上限，请明天再来。」）。

要出的帧：默认态（带麦克风入口）、按住说话且正在出字、上移取消、等待回答、回答已到且正在朗读、没听清。

### 三、悬浮窗

App 退到后台后，它浮在别的应用上面。底下的应用请画成中性的示意界面，聊天应用、相机取景、手机桌面各一张。**不要仿任何真实应用的界面和商标。**

**头像**

- 约 56dp，可以拖动，松手后贴到屏幕左边或右边。
- 贴边待命久了，缩进去一半并变淡。请设计这个收起态。在大园子里它可能一连十几分钟无事可做，这个状态会是游客看到最多的样子。
- 头像旁边会冒出一句话：到站时「已到达 同德殿」或「已到达 九龙壁」；被唤醒时「我在，请说」；识别过程中的实时文字；回答的前两行。请设计这个气泡，以及它在头像贴左、贴右时的样子。地点名很长时怎么办也请给出来（用「兰徽幻影——溥仪“御纹章”文物展」试）。
- 长按头像就是按住说话，不用先点开面板。

**对话面板**（点一下头像展开）

- 不盖满全屏：宽约屏宽的 90%，高不超过屏高的 60%，从头像所在的一侧展开。要让人随时回得去原来的应用。
- 标题行：当前这位导览员的名字（示例用「阿瑞」）和当前位置，右边是收起按钮。悬浮窗不知道游客会在哪个景区，所以位置要带上景区名，三种情形：「北海公园 · 位于 九龙壁 热区」「伪满皇宫 · 未进入热区」「不在任何景区内 · 最近的是北海公园，距入口 2.3 公里」。
- 对话流里有三种东西：到站消息（「已进入热区：同德殿 · 14:32」，带「听介绍」）、我的提问、回答（标「AI 生成」，带朗读按钮）。
- 输入行：文字框、发送、按住说话。
- 底部两个动作：「打开地图」「停止陪伴」。一行小字：「这里的对话只有你自己看得到」。

要出的帧：头像六种状态各一张、收起态、带气泡的两种贴边方向、长按说话中、面板展开、面板加软键盘。

### 四、后台到站提醒

游客走进热区而 App 不在前台时，三样东西同时出现：

1. **系统通知**。屏幕顶部弹出的一张，锁屏上的一张。两个动作「听介绍」「打开地图」。标题和正文请两处景区各出一版：
   - 标题「已到达 同德殿」，正文「伪满皇宫 · S 级 · 建议停留约 30 分钟」。
   - 标题「已到达 九龙壁」，正文「北海公园 · A 级」。北海还没有建议停留时间，正文就短一截。
2. **悬浮窗头像**冒出气泡「已到达 同德殿」，同时进入「在说」状态。它会说出「已到达同德殿。」
3. 点了「听介绍」之后：头像保持「在说」，旁边是一个很小的播放条，显示正在读的那一句，有暂停和停止。

另外还有一条**常驻通知**，只要陪伴模式开着它就在：标题「Ari Travel 正在陪伴导览」，动作「暂停唤醒」「停止陪伴」。正文跟着位置变，三种各出一版：「北海公园 · 位于 九龙壁 热区」「伪满皇宫 · 未进入热区」「不在任何景区内 · 最近的是北海公园，距入口 2.3 公里」。

App 在前台时的到站仍然是现有的顶部横幅，不用改。

### 五、语音唤醒

在一个中性的示意应用上面，连续六帧。这一组用北海公园的九龙壁（第二节的语音问答用的是伪满皇宫的同德殿，两处都要出现）：

1. 待命。头像是待命态，状态栏右上角有系统的绿色麦克风标记。
2. 游客说「你好阿瑞」。头像转为「在听」，气泡「我在，请说」。（这里有一声提示音，标注一下即可。）
3. 游客说话，气泡里实时出字：「九龙壁是什么时候建的」。
4. 在想。
5. 在说。气泡变成一张小卡片：回答的文字、「AI 生成」、停止按钮。
6. 回到待命。

两个变体各一帧：

- **锁屏时**没有悬浮窗。回答以通知的形式出现在锁屏上，同时用语音读出来。
- **App 在前台时**，同样的过程发生在导游地图上方。

另外有三句口令：「讲一讲」（读当前景点的介绍）、「打开地图」、「停」。怎么让人知道有这几句话，请给一个方案，放在首次开启唤醒时或设置面板里都可以。

### 六、陪伴模式与权限

**入口**：导游地图顶栏、铃铛旁边多一个图标，请设计。点开是一个底部抽屉「陪伴模式」。

**导览员**：抽屉最上面一行，显示当前这一位的头像和名字，点开可以换。换人的界面请设计：每位一张卡片，有头像、名字和一句自我介绍，当前选中的有标记；要留得出以后加第三位、第四位的位置。两位共用一个声音，不要设计「试听」。自我介绍的示意文案：

- 阿瑞：「我是阿瑞，Ari Travel 的导览员。你走到哪儿，我讲到哪儿。」
- 小爱：「我是小爱，名字取自爱新觉罗。这几处宫苑的旧事，我带你看。」

**四个开关**

| 开关 | 说明文字 | 需要的权限 |
|---|---|---|
| 后台到站提醒 | App 不在前台时，走进热区照样提醒 | 定位、通知 |
| 悬浮窗助手 | 在其他应用上方留一个头像，随时提问 | 显示在其他应用上层 |
| 语音播报 | 到站时读出地点名，回答自动朗读 | 无 |

- 语音唤醒下面要有一段说明：「开启后状态栏会一直显示麦克风标记，耗电和流量都会增加。开启期间麦克风收到的声音会上传到服务器，包括说出唤醒词之前的。」

**小米手机专项**，标题「让它在后台不被关掉」。五项：悬浮窗、后台弹出界面、自启动、省电策略设为「无限制」、悬浮通知。其中几项 App 查不出是否已经打开，所以每一行是一个「去设置」，加一个由用户自己勾的「我已设置」。这一块信息多，容易把人吓退，请想办法让它看起来是能一步步做完的事。

要出的帧：顶栏入口（普通态，以及「还有设置没做完」的提醒态）、抽屉全关、抽屉全开且权限齐全、有一项权限没给、小米专项做到一半、换导览员。

一屏，讲清用到什么、什么时候上传。下面的文案是示意，可以调措辞，不要改变事实：

## 平台的硬约束（设计要落在这些之内）

- Android 手机竖屏，按 360 × 800 dp 出图，带状态栏和底部手势条。
- 测试机是小米。通知、锁屏这些系统界面画成通用 Android 的样子即可，不必仿某个品牌。
- **系统通知只能用标准模板**：小图标、应用名、时间、标题、正文、最多三个文字动作，可选一张大图标。版式改不了。
- **麦克风在用时，状态栏右上角的绿色标记是系统画的，藏不掉。** 凡是在听的帧都要画上。
- **悬浮窗不能出现在锁屏上。** 锁屏时只有通知和声音。
- 悬浮窗头像只在 Ari Travel 不在前台时出现。
- 悬浮的东西底下是别人的界面，不能假设背景颜色，要自带底色和描边或阴影。
- 可点的东西不小于 48dp。主要操作放在拇指够得到的下半屏。
- 室外强光下要看得清：正文与底色的对比度不低于 4.5:1，关键信息不要用浅灰小字。
- 只做浅色主题。

## 交付

- 一张画板，按「一」到「七」分组。每帧 360 × 800 dp，帧下标注它是哪个状态。
- 一页组件表：agent 头像（每种画风下的阿瑞和小爱，状态数见第一节）、麦克风按钮各态、朗读按钮各态、气泡、对话面板里的三种消息、两种通知。
